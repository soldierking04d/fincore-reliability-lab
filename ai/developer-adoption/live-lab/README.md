# 本地 AI 研发验证工作台

入口：<http://127.0.0.1:4400/>。只在本机运行，不部署腾讯云。

公网只读证据：<https://124.223.164.254/#ai-delivery-evidence>。公开的是经过白名单导出的 `public-evidence.json`，不是本机 `.local` 目录；服务器不部署此执行器，不提供模型调用、候选执行或写入接口。

## 启动

需要 Node 24+、macOS sandbox-exec、JDK 21+；真实 AI 模式另需已登录的 Codex CLI。

```sh
node ai/developer-adoption/live-lab/server.mjs
```

本机默认使用现有 JDK 26 编译 `--release 21`，CLI 为 ChatGPT 应用内自带可执行文件。不下载依赖。换电脑时用 `AI_LAB_JDK`、`AI_LAB_CODEX` 指定路径；`AI_LAB_MODEL` 可指定账号可用模型。不填写则由 CLI 服务决定，不虚构已解析的具体型号。

## 真实演示

1. 建立任务：12 个合同用例由原 workshop 提供，先编译运行受信旧版。正常行为和缺陷分别显示。
2. 生成候选：只把需求、旧版、合同用例和失败反馈发送给模型。CLI 禁用 shell、统一执行和多 Agent，不载入用户配置或规则；不授予修改仓库权限。模型只返回结构化源码、方案和风险。没有模型连接时明确失败，不自动切换参考答案。
3. 审查代码差异，勾选同意执行候选；独立执行器编译一个源码及受信探针，运行原始 12 个测试。模型不写或更改验收用例。
4. 测试失败可携带实际失败结果再生成一次；每任务最多两次模型调用，不自动空转。编译和环境错误不会算作预期红。
5. 全绿后填写人工评审意见并验收。没有自动合并、Git 推送、发布、数据库或钱包操作。
6. 查看/下载 JSON 报告，重启后可读历史；正在运行的任务在重启后标记中断，不自动补调用。

“参考实现”和“漏项演练”是显式夹具模式，不调用模型、不展示虚构 Token；两者都会真的编译执行 Java。漏项候选只修整数溢出，不能通过完整需求。

## 计量与可靠性

- 各阶段用单调时钟测实际执行耗时；人工等待＋审查区间另外记录，不能声称为纯审查工时。
- Token 只读取 CLI `turn.completed.usage`，缓存输入包含在输入内。失败/取消若未返回用量标为未知；不能当作零消费，也不能将已知小计当完整总量。
- 三项单价由操作者填写，单位 USD/百万 Token；折算公式为 `(input-cached)*inputPrice + cached*cachedPrice + output*outputPrice` 再除一百万。金额是估算，不是订阅扣费。未填或有未知用量不折算。
- 每次模型调用 180 秒上限，编译 20 秒，单用例 4 秒；输出有字节上限，取消终止子进程组。
- 任务串行、状态版本校验、一次只有一个活动任务；报告先临时文件再原子重命名；保留最多 100 个任务，满后拒绝创建而非删除记录。
- 文件摘要绑定旧版、候选、用例和探针；历史记录用于审查，不重新执行历史 JSON 中的命令。

## 隔离边界与限制

候选 Java 在 macOS sandbox-exec 中运行，默认拒绝网络，仅允许读取系统、指定 JDK 和本次验证目录。编译阶段允许写验证目录；候选运行时仅可写专用临时子目录，不可改写源码、探针或编译产物。使用系统 dyld 引导规则兼容 macOS 27。限制 JVM 堆、线程栈、处理器数量；这不是容器或强多租户安全平台，不防御所有 CPU/磁盘资源耗尽。本机操作者应先审查候选；不支持隔离的环境拒绝执行。

CLI 的账号凭据仍由 CLI 读取，应用不复制密钥、不输出凭据。真实模式会消耗账号额度，可能在 CLI 自有目录留下内部运行记录；应用只保存候选、用量和固定进度，不持久化原始 CLI 事件。仅发送本例白名单教学源码，不发送完整仓库、访客数据或生产配置。

HTTP 仅监听回环地址，校验 Host、Origin、Fetch-Site；写操作使用每进程随机令牌。静态资源白名单，不提供 `.local` 文件访问。无公网身份认证，不能直接暴露端口；其他本机进程仍可访问，不构成对本机恶意软件的保护。

这是完整工程路径的一个限定案例，不是全仓库自主开发平台，也不是模型盲测。12 项公开用例不能证明生产正确或真实公司提效；暂无人工基线，不能宣称节省多少工时。

协议依据：[Codex 非交互运行](https://developers.openai.com/codex/noninteractive/)。单元测试：`node --test ai/developer-adoption/live-lab/*.test.mjs`。
