# 本地链上交易预检工作台（第三阶段）

这一阶段把 PAPER 状态机和 READ_ONLY 检查向真实池子推进：浏览器连接钱包只读公开地址，服务端读取固定 FCLAB / WSOL 池，用真实链上数据计算买卖报价并执行**未签名模拟**。

**没有签名按钮、没有交易广播接口、没有真实买卖。** `SIMULATION_PASSED` 不是成交，永远同时返回 `executionAllowed: false`。本阶段不宣称完成真实买入—持仓—卖出闭环。

## 启动与操作

要求 Node.js 24；在此目录执行：

```sh
npm ci --ignore-scripts
npm test
npm run build
npm start
```

打开 `http://127.0.0.1:4398/`，选择已安装的 Solana 标准钱包，点击连接并检查公开地址。随后选择 BUY 或 SELL、输入数量、运行只读预检。解锁钱包由本人完成，页面不索取密码、私钥、助记词。

- BUY 最多模拟 0.0001 SOL，SOL 转入已存在的 WSOL 关联账户后交换 FCLAB。
- SELL 最多模拟 10,000 FCLAB，输出为 **WSOL**；不自动解包为 SOL、不关闭任何账户。
- 滑点上限 50 基点。池费和网络费另外显示，不等于滑点费用。
- 两个关联代币账户必须已经存在。缺少时明确阻断，本页面不创建账户。
- 切换账户、断开钱包或修改数量时旧报价立即作废。过期/异常不自动重试。
- 公开地址不构成钱包所有权证明；连接也不是服务端身份认证。

## 隔离与信任边界

```text
本人浏览器 / 钱包扩展
  └─ 用户点击连接 → 只读公开 Solana 地址
       └─ 127.0.0.1:4398（独立 origin、独立进程）
            ├─ 固定地址、整数金额、会话/CSRF、单并发准入
            ├─ 固定池快照 → 报价 → 零签名 legacy 交易
            └─ 官方 Solana RPC 白名单 → 模拟 / 同笔资产变化检查
                    └─ 展示结果；无签名、无广播、无记账

旧公网演示 / 数据库 / 钱包发行辅助页 ← 不调用、不挂载、不共享会话
```

服务仅监听回环地址；不是公网交易网关。CSRF 令牌存在浏览器内存，随机会话 Cookie 为 HttpOnly / SameSite=Strict；不使用 localStorage 保存钱包连接、地址或密钥。固定静态文件映射，不提供通用 RPC 转发。

RPC 使用固定主网端点和创世哈希，设置完整请求期限、响应大小及并发限制，拒绝重复 JSON 字段和不安全整数。所有资金使用原子单位十进制字符串和 BigInt。只接受单付款人、全零签名的 legacy 模拟交易。

模拟前后的资产差额必须来自**同一次模拟响应**；不能拿两个时间点的余额查询冒充同一笔交易的变化。节点不提供足够证据就阻断，不能改为绿色成功。

## 本地验收 → 腾讯云

先运行单元测试、真实主网只读预检、浏览器钱包连接及断开验收，记录真实结果后再发布。公开展示站点不是资金执行环境，不能直接复用其 origin 的钱包授权。

安全的初始腾讯方案是新建独立服务、独立目录、独立运行用户，仅绑定服务器回环端口，通过 SSH 本地转发访问；不改旧站点首页、Caddy 路由、数据库或其他容器。上线前必须校验服务器 SSH 指纹并确认资源和端口。直接公网入口另需独立 HTTPS origin 与访问控制。

本文件描述实现和验收方法；实际通过项、未完成项以 `VERIFICATION.md` 为准，不能把设计当成已经部署。

2026-09-15：独立服务已安装至腾讯云，私有入口为 SSH 隧道上的 `http://127.0.0.1:4399/`；云端官方 RPC 连接仍失败，预检明确阻断。访问、隔离、恢复和未完成项见 [部署说明](deploy/README.md)。本机 4398 入口的 BUY / SELL 再次模拟通过，不把本机结果当作云端通过。
