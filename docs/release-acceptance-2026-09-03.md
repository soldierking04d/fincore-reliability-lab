## 二、已修复的问题

1. **测试不再静默漏跑。** CI 强制数据库可用，并检查 JUnit 报告：关键集成测试缺失、零执行、跳过、失败或错误均阻断发行。完整结果为 92 项执行、0 跳过、0 失败、0 错误，包含 13 项合约数据库并发与回滚验收。
2. **真实结果与教学回放分开。** 首页默认真实模式。报告缺字段、超时或检查失败不再被默认值补成成功；成功必须关联运行编号和完整业务检查。写入场景不自动重试。
3. **监控显示实际采样。** CPU、业务 HTTP QPS、JVM 堆和活动数据库连接来自监控查询；不可用、陈旧或缺失时显示缺数，不使用教学曲线补值。它们是应用级指标，不归因于某一次实验。
4. **构建与版本统一。** 两种部署目标在源代码中选择接口路径，不再改压缩后的脚本。公网首页及 8 个引用资源与生产构建逐一核对，内容一致。
5. **发布只更新本项目应用。** 整机初始化与应用发行拆开；普通发行不安装软件、不重启 Docker、不修改全局网络、Swap 或其他项目。

前端新增 13 项契约测试全部通过，覆盖不完整响应、检查失败、429、服务错误、超时、异步结果未完成、两种部署路径和缺失监控等情况。类型检查、生产构建、修改文件的定向 Lint 均通过。此处不是浏览器逐按钮点击或视觉验收记录。
